# КТО ТЫ? ✳ — лаборатория необычных тестов

Небольшая браузерная игра на русском языке. **10 тестов, 60 уникальных вопросов, 40 результатов** — от мультгероев и котов до мемов, киножанров и привычек принятия решений.

### Что умеет

- Каталог с поиском и фильтрами по темам.
- 10 полностью самостоятельных тестов по 6 вопросов с четырьмя вариантами ответа.
- Результат с уникальным описанием, сильными сторонами, шутливым советом и распределением ответов.
- История всех прохождений: дата, результат, повторный просмотр и удаление записей.
- Продолжение начатого теста после перезагрузки.
- Избранные тесты, случайный тест, возможность перепройти.
- Поделиться результатом: через системное меню или копирование текста и ссылки.
- Адаптивный дизайн для телефонов и компьютеров, управление клавишами **1–4**, **Enter**, **←**.
- Без регистрации, сервера, базы данных и библиотек.

### Как запустить

**Вариант 1.** Скачайте репозиторий и откройте `index.html` в современном браузере.

**Вариант 2. GitHub Pages.** Откройте настройки этого репозитория: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Когда GitHub Pages завершит публикацию, игра будет доступна по адресу:

https://golunovoleg111-rgb.github.io/testing/

Этот адрес заработает **после включения GitHub Pages** в настройках репозитория.

### Какие тесты доступны

1. **Кто ты в мультвселенной?** — архетипы мультгероев.
2. **Как ты заряжаешь батарейку?** — привычные способы восстановления энергии.
3. **Какой ты мем в понедельник?** — шуточный портрет утреннего состояния.
4. **Какой ты кот?** — четыре пушистых характера.
5. **Какой ты мультзлодей?** — сценарный злодей с неожиданной глубиной.
6. **Кто ты в компании друзей?** — твоя роль в дружеском чате.
7. **Как переживёшь зомби-апокалипсис?** — сюжетные ситуации на выживание.
8. **В каком жанре твоя жизнь?** — свой собственный киножанр.
9. **Как ты принимаешь решения?** — привычные стратегии выбора.
10. **Кто ты в 03:17 ночи?** — ночные мемы и странные идеи.

### Как работает расчёт

Каждый вариант ответа соответствует одному из четырёх результатов внутри конкретного теста. Ответ даёт результату один балл, а на финише побеждает образ с самым высоким счётом. Если счёт одинаковый, побеждает тот из лидирующих образов, который был выбран позднее. На экране результата отображается распределение баллов по всем четырём образам.

Визуальный порядок вариантов перемешивается **стабильно** для каждого вопроса: при возврате назад варианты остаются на своих местах. Прогресс сохраняется после каждого ответа.

### Хранение данных и приватность

История, избранное и один текущий незавершённый тест хранятся в **localStorage** текущего браузера. Они не синхронизируются между устройствами и могут исчезнуть, если очистить данные сайта. Ссылка при отправке результата ведёт на **сам тест**, а не на локальную историю другого пользователя.

Психологические темы здесь развлекательные и **не являются психологической диагностикой**. Вопросы, тексты и результаты созданы специально для этой игры; вместо чужих изображений используются эмодзи и CSS-иллюстрации.

### Изменение контента

В `tests.js` каждый тест содержит `id`, тему, заголовок, шесть `questions` и четыре `results`. В каждом вызове `question(...)` четыре ответа идут в порядке четырёх `results`; приложение самостоятельно перемешивает их отображение. Новые тесты автоматически появляются в каталоге и категории.
